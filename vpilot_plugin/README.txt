OPS ROOM vPilot Bridge, v0.20.0

The desktop Host Console installs this bridge automatically from System Setup. It uses the official RossCarlson.Vatsim.Vpilot.Plugins.dll already installed with vPilot under %LOCALAPPDATA%\vPilot. The official API DLL is not replaced or modified.

The bridge provides:
- vPilot/VATSIM connection state and callsign
- private-message receive notifications and replies
- radio and broadcast text events
- controller and ATIS events
- SELCAL alerts
- Mode C and IDENT actions

Restart vPilot after installing or updating the bridge.
